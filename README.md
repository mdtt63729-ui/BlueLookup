# Demo Lookup

A synthetic demo dataset for a number-to-info lookup: **10,000 placeholder records**.

Everything in `data2.json` is fictional. Phone numbers look like `DEMO-PHONE-001001`, emails end in `example.invalid`, Aadhaar fields are `AADHAAR-DEMO-…` placeholders, and every record carries `"is_real_person": false`. No real personal data is included.

## File

- `data2.json` — 10,000 records (ids `DEMO-001001` … `DEMO-011000`), searchable on `id`, `phone`, `name`, `aadhaar`.
