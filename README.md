# Number Lookup demo (GitHub Pages)

## Publish
1. Create a GitHub repository (public is simplest for GitHub Pages).
2. Upload `index.html`, `data.json`, and `data2.json` to the repository root (same folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

The page loads both JSON files using relative paths, so it works on a project Pages URL as long as all three files are in the same folder. It uses fictional demo records only.
